# E-Commerce SQL Data Analysis Project

## Project Overview
This project analyzes e-commerce sales data using PostgreSQL and SQL.

## Database Tables
- Customers
- Categories
- Products
- Orders

## SQL Skills Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- Multi-table JOINs
- Revenue Analysis
- Month-wise Analysis

## Key Analysis
- Total number of orders
- Total quantity sold
- Customer-wise analysis
- Product-wise quantity and revenue
- Category-wise revenue
- Month-wise revenue
- Customer and category revenue analysis

## Tools Used
- PostgreSQL
- pgAdmin
- SQL
