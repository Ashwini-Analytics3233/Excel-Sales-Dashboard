# Sales Performance Dashboard

Project Description

An Excel dashboard created to analyze sales performance using Pivot Tables, Charts, Slicers, Filters, and Power Query.

Key Metrics

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

Key Analysis

- Sales by Region
- Sales by Category
- Sales by Payment Mode
- Sales by Sales Person

Tools Used

- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Power Query

Project Features

- Data cleaning
- Interactive slicers and filters
- Pivot table analysis
- Visual charts and graphs
- Interactive dashboard for quick insights
